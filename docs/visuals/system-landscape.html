Map 01 / system boundaries

The CLOVERSIGHT system

The three browser surfaces share visual and authentication code. The primary Region owns identity, billing, scheduling, and metadata; browser captures and evidence remain in their selected AWS Regions.

Local runtime

src/server.mjs serves the static sites and API with FileStore and LocalAssets. It runs the same product services against local data.

AWS control plane

infra/cloudformation/webwatch.yaml defines CloudFront, Cognito, HTTP API, DynamoDB, primary S3, queues, workers, SES, WAF, and alarms.

Regional plane

infra/cloudformation/regional-capture.yaml defines a queue, browser Lambda, and private evidence bucket in each configured secondary Region.
