CLOVERSIGHT
Product logo derived from the supplied Red Clover identity

DESIGN
The original clover blossom sits inside a faceted magnifying-glass lens.
A clover leaf sweeps under the flower and extends into a square-ended handle.
The outlined wordmark uses the supplied Archivo font at weight 900, width 125.

FILES

cloversight-dark.svg             Horizontal logo for ink or plum backgrounds
cloversight-mark.svg             Standalone symbol for light backgrounds
cloversight-mark-dark.svg        Standalone symbol for ink or plum backgrounds
cloversight-mark-small.svg       Simplified symbol for 16–24 px use, light backgrounds
cloversight-mark-small-dark.svg  Simplified symbol for 16–24 px use, dark backgrounds
cloversight-preview.png          Presentation sheet, with background colours

SELF-CONTAINED SVG
All six production SVGs have transparent backgrounds and explicit hex fills.
No CSS variables, external styles, scripts, linked fonts, embedded raster images,
filters, or external assets are required. Text is converted to vector outlines.
Each SVG includes a meaningful title and can be opened directly in a browser
or vector editor, or used as a normal HTML image.

Example:
<img src="cloversight.svg" width="344" height="48" alt="Cloversight">

Use the standard marks at 32 px or larger. Use the simplified mark at 16–24 px.
The full lockup is best at 344 px wide or larger. Scale proportionally.
Leave clear space of at least one handle width around the logo.

PALETTE
Light: plum #601350, leaf #1A4B36, clover #D8538F, highlight #F2B8CF,
       wordmark ink #16101A.
Dark:  lens #F2B8CF, leaf #4E9A76, wordmark paper #F0EBE1.
       Blossom colours remain unchanged.

The light and dark versions are deliberately separate, fully packaged files;
neither requires a theme switch or inherited colour to display correctly.

Archivo's supplied SIL Open Font License is included in Archivo-OFL.txt.
